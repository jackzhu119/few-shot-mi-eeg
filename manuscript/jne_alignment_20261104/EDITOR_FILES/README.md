# Editor-facing files

Use `Cover_Letter_with_Editorial_Statement.pdf` in the Cover Letter attachment field. It contains the current cover letter followed by the existing editorial statement, with unchanged page text. This avoids a dangling reference to an unattached statement when the portal provides only one cover-letter file field.

The two source PDFs remain separate for traceability. The combined file is editor-facing; do not designate it as public supplementary research data. This file does not contain or claim to substitute for the actual current related submission discussed in the statement; that document should be supplied to the editor through the appropriate channel.

The seven primary manuscript/supplementary PDF/CSV files are unchanged. No new scientific analysis or journal-system action was performed.
