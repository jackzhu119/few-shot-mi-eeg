# Local results

Experiment outputs are ignored by Git. Run the synthetic smoke workflow to create
local JSON reports. Synthetic classification scores validate software only and are
not neuroscientific findings. Small audited verification reports belong in
`research_logs/`; raw EEG, participant identifiers, weights and large files must not
be committed. Real-data adapters and study-specific event mappings require review
before actual dataset results can be reported.
