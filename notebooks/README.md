# Reproducible exploration

Put exploratory notebooks here after the first licensed, documented dataset
subset is available. Production preprocessing and evaluation belong in the
installable package. Notebook plots must identify the actual data source and
cannot interpret offline geometric stability as proven human skill retention.

`netbci2026_behavior_sessions.ipynb` is an executed companion to the verified
session analysis. It reads saved outputs only: 19 participants' behavior, but
only one participant's EEG. It neither downloads data nor trains models.
The HTML and native figures accompany the notebook; see
`../docs/netbci_behavior_session_analysis.md` for source and inference limits.
