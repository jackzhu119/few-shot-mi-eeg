# Learning-Preserving Co-Adaptive Brain–Computer Interfaces

面向神经控制学习能力保留的人机协同自适应脑机接口。

Core question: How should brain–computer interfaces adapt without compromising human neural skill acquisition?

This is a newly initialized repository. Active infrastructure development is on
`research/learning-preserving-bci`; select that branch for the package, research
protocol, dataset and code-reuse audits, tests and validation records.

Offline decoder performance and representation drift do not establish human neural
learning or skill retention. Synthetic fixtures validate software only.

The first-paper repository is a read-only reference. Its source code and results
are not copied into this project. No large EEG downloads or paid compute are part
of this bootstrap.
