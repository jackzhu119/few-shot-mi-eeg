## 3. 先排除一个容易混淆的标量修正

设独立源/目标均值估计为S和T，真实域差平方为D²，均值噪声方差迹为v_s和v_t。融合估计(1−α)S+αT的目标平方风险为

\[
R(\alpha)=(1-\alpha)^2(D^2+v_s)+\alpha^2v_t.
\]

对α求导得到

\[
\alpha^*=\frac{D^2+v_s}{D^2+v_s+v_t}.
\]

若d²=||T−S||²，并令Dhat²=max(d²−v_s−v_t,0)，在d²>v_s+v_t时，代入恰好得到αhat=1−v_t/d²，也就是V2已有规则。低差异截断分支会变化，但“公式多写一个源方差”本身不足以证明实质算法增量。本轮更重要的检验是共同/判别变化的分离、方向性噪声与预测不确定性。

## 4. 候选算法：源参考切空间中的共同位置—半判别对比融合

### 表示与噪声

每个trial使用当前已固定窗口，计算trace归一化协方差并以ρ=0.1作SPD正则化。**R_s仅由source TRAIN拟合**，对所有support预算和query保持固定。特征为

\[
z=\operatorname{vech}_{\sqrt2}\{\log(R_s^{-1/2}C R_s^{-1/2})\}.
\]

通道数由实际输入推导；22通道时p=253。当前support不重新拟合参考白化器，可避免将极少support估计的参考变化与类别变化混在同一步中。trace归一化和identity ridge不具备一般线性传感器混合下的严格仿射不变性，本研究不声称该不变性。

对每个域d，定义

\[
m_d=(\mu_{d0}+\mu_{d1})/2,\quad h_d=(\mu_{d1}-\mu_{d0})/2,\quad\theta_d=[m_d;h_d].
\]

m表示两类共同位置，h表示半判别对比，二者具有相同单位。各类特征内协方差B_dc使用固定0.1收缩，U_dc=B_dc/n_dc。均值观测噪声为

\[
V_d=\tfrac14\begin{bmatrix}U_{d0}+U_{d1}&U_{d1}-U_{d0}\\U_{d1}-U_{d0}&U_{d0}+U_{d1}\end{bmatrix}.
\]

分别估计共同位置和判别对比的变化尺度：

\[
\tau_j^2=\max\left\{\frac{\|\theta_{tj}-\theta_{sj}\|^2-\operatorname{tr}(V_{s,jj}+V_{t,jj})}{p},0\right\},\quad j\in\{m,h\}.
\]

T=diag(τ_m²I,τ_h²I)，M=V_s+T。完整观测时，融合均值和协方差为

\[
\widehat\theta=\theta_s+M(M+V_t)^{-1}(\theta_t-\theta_s),
\quad P=M-M(M+V_t)^{-1}M.
\]

实际代码使用masked线性高斯更新及Joseph形式计算P，减少相减导致的数值误差。n_c=1时用固定源类内协方差作方差代理；缺失类别时只使用已观察类别，令不可辨识的域变化T=0，未观察类别保留源均值。缺失类别不会触发整队列中断，也不会用未来标签补齐。

### 预测与数学结论的范围

类别均值为m±h；等类别先验下，后验预测使用

\[
Q_c=W+A_c P A_c^\top,\qquad A_c=[I,\pm I],
\]

其中W为固定源类内协方差。类别分数包含Gaussian log determinant与二次型。

在指定线性高斯模型、固定已知噪声条件下，完成平方可得上述后验；任一候选估计a的条件平方风险为tr(P)+||a−θhat||²，故后验均值最小化该条件风险。对新特征积分得到上述预测协方差。这不等于plug-in协方差下的EEG BA必然改善。R_s和类内协方差本身由有限数据估计，代码只传播**给定表示条件下的类均值不确定性**，未完整传播参考R_s的不确定性。B/n近似也隐含试次独立；序列相关压力模拟专门检查该假设失配。

### 九臂与主对照

| 方法 | 问题 |
| --- | --- |
| source_tangent_frozen | 固定源切空间解码基线 |
| tangent_pooled | 同表示、同源W，源＋support均值池化 |
| tangent_refit | 同表示，源＋support的均值和类内协方差重新估计 |
| eb_point | 保持候选后验均值，但预测时去掉P |
| eb_predictive | 完整候选 |
| eb_isotropic | 将方向性噪声替换为各向同性，保留后验预测P |
| eb_coupled | τ_m与τ_h改为共同尺度，其余保持一致 |
| eb_no_source_noise | 使用相同T，仅移除源均值噪声V_s |
| eb_no_shift | T=0，只作有限样本均值更新 |

新轮预先指定的主要几何对比为**eb_predictive−tangent_refit，20标签上限**；同时必须报告**eb_predictive−既有EA-CSP**这一强参考。后者直接读取V2保存的原始预测/指标，并核对实际trial IDs与标签，不伪造一次新fit。V2原主终点和负结果保持不变。

## 5. 神经发现：把源模型质量、BN、Dropout和函数约束拆开

### 两个来源条件

- **reuse_v2**：只读复用现有18个源模型，source TRAIN40/validation20；不触发源模型替代重训。
- **pooled_source**：三个固定种子各训练一个共享模型，使用六人的source TRAIN共240、source validation共120，100epochs按源验证CE选模型。各参与者自己的source query和所有目标query均不用于预训练/选epoch。

池化条件使用更多跨参与者源标签，不把与40标签条件的差直接包装为纯算法优势。共享源模型会引入共同训练来源；六人bootstrap是给定已训练模型下的描述性不确定性，不覆盖重新抽取源训练队列的全部变化。

### 八种核心更新策略

| 策略 | 可训练参数 | BN buffers | Dropout |
| --- | --- | --- | --- |
| frozen | 无 | 固定 | 关闭 |
| head_fixed | 分类头 | 固定 | 关闭 |
| full_fixed | 全参数 | 固定 | 关闭 |
| full_adaptive_bn | 全参数 | 更新 | 关闭 |
| full_adaptive_bn_dropout | 全参数 | 更新 | 开启 |
| bn_affine_fixed | 仅BN affine参数 | 固定 | 关闭 |
| bn_stats_only | 无optimizer，仅一次support统计更新 | 更新 | 关闭 |
| trust_fixed | 全参数，带函数约束 | 固定 | 关闭 |

所有有optimizer的适配固定20epochs、batch16、AdamW、lr1e−4、weight decay1e−4、AMP关闭；不按query选epoch。独立采样生成器保证各策略同seed/session/budget下使用同一采样顺序，Dropout消耗的随机数不会改变后续shuffle。

### 函数约束及剂量探索

trust_fixed尝试降低support CE，同时约束参与者自己source TRAIN40上的平均KL：

\[
\overline{KL}(p_{teacher}\|p_\theta)\le\delta.
\]

每个AdamW提议采用最多12次减半回溯；未找到可行更新时恢复参数和Adam状态，保留提议/拒绝次数，继续固定数据遍历。这是算法内步长求解，不是重新启动fit。核心δ=0.01，另外完整执行δ=0.001和0.1两个发现分支，不重复其余对照或源拟合。

Pinsker与Jensen给出已观察锚点上的平均TV≤sqrt(δ/2)，三档约为2.24%、7.07%、22.36%。它不保证argmax标签、source BA、未来query BA或人类技能保持；例如非常接近0.5的类别概率可在小KL内翻转类别。弱源教师也可能限制有效目标更新，因此单独比较两个来源条件。

主要神经对比为每个来源条件下**核心δ=0.01的trust_fixed−full_fixed，20标签上限**。BN、Dropout、BN affine与KL剂量为明确的探索性机制比较。功能蒸馏、KL信赖域和BN适配已有文献，不能单独声称首创。

## 6. 已知机制模拟与新颖性核查

固定384场景：p∈{16,64}，每类source数∈{10,20,100}，每类support数∈{1,2,5,10}，变化类型∈{无变化、共同变化、判别变化、二者都有}，各向异性∈{1,20}，试次序列相关∈{0,0.5}；每场景50个配对随机重复，所有9方法使用同一组source/support/query抽样。记录均值MSE、BA、CE、binary Brier，不跨场景挑选唯一赢家。每个方法完成后保存，恢复只补未完成cell；原失败cell保留。序列相关压力条件专门检验B/n均值噪声近似在试次不独立时的失配；它不是让估计器提前知道真实相关参数。

所有模拟标为synthetic=true/software_validation_only=true，属于机制和软件分析，不能代替独立真实EEG证据。它们使用NumPy CPU；GPU只用于对应的神经训练，不把CPU模拟声称为GPU加速。

已聚焦核查EA、RPA、RCSP、AdaBN、L2-SP、2025纵向fine-tuning、latent alignment、TRPO及LwF。现有几何对齐、源锚定和神经BN更新均不是本项目首创。候选增量是**共同/判别变化的分离、矩阵噪声融合与匹配消融**；能否构成有竞争力的算法贡献取决于真实结果与独立外部复核。全文、摘要与元数据读取范围见[文献记录](../research_logs/paper2_discovery_v3_preparation_20261026/literature_FINDINGS.md)及JSON来源凭据。
