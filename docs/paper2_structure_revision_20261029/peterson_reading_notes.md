## What was read

The article moves from an operational recalibration problem to mathematical domain/transport definitions, a backward mapping, two information-access scenarios, datasets, scenario-specific comparisons, participant/run results, computational cost, and interpretation. A fixed CSP feature extractor lets the experiment focus on what transport changes. Forward variants fit a classifier after moving source features; backward variants map target features into the existing classifier’s domain. Block-wise adaptation uses accumulated preceding target information. Sample-wise adaptation additionally includes the current trial; label-informed variants can use its indicated task. This makes access timing central to interpreting results. The source-subset and regularization search described in Section4.1 is a separate method-selection step. Tables distinguish consecutive blocks, individual participants and execution time. The discussion connects these observations to the intended operating scenario.

## Mapping to this project’s own evidence

The following are editorial decisions based on this repository’s experiments, not new Peterson-derived scientific claims:

1. Open with the actual question the saved paired contrasts answer: how much benefit comes from changing spatial features after the classifier receives the same labels? Define the LDA-only/Full comparison before presenting broader update-mode results.
2. Give each existing experiment one clear job. The original Kumar endpoint quantifies the spatial component. Prediction transitions reconstruct its gain. Session/participant summaries locate it. The separate BNCI experiment compares support-only alignment with refitting. V2/V3 controls clarify additional estimator choices.
3. Put chronological source/support/query access in one clear Methods subsection. The project’s fixed current-session support and later whole-run query are its own protocol; the comparison does not accumulate previous query information or use the current query label for adaptation.
4. Present paired participants and chronological sessions/runs using this project’s recorded predictions. Avoid replacing a participant endpoint with a large count of nested predictions, seeds or blocks.
5. Frame the contribution as a matched-information component analysis and its measured findings. No optimal-transport solver, forward/backward mapping experiment, published-source timing result, or published-source classification result was generated by this project.
6. Learn generic organization without copying sentences, the distinctive transport derivation, the original figures, its data or its numerical results. A standard introduction–methods–results–discussion arrangement alone does not require a new scientific citation; discussing this specific transport method or using its substantive ideas does require attribution. Existing related-method citations must continue to support the manuscript’s actual claims.
