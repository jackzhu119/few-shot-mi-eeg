七、P1：借用论文1的弱类别覆盖与联合受益
────────────────────────

在每个参与者×会话×种子的原始终点单位上计算：
- rL、rR：左右类别召回率；
- BA=(rL+rR)/2；
- W=min(rL,rR)：弱类别召回率；
- H=abs(rL−rR)：类别召回差距。
验证 W=BA−H/2。

使用 H 表示类别差距，避免与旧脚本中表示净增益的 G 混淆。
先逐会话/种子计算非线性指标 W、H，再按各研究原权重汇总。不能对队列平均召回取 min，冒充平均弱类别召回；不能取 mean 后再 abs，冒充平均类别差距。

优先输出 EA−Full，同时保留 Full−LDA-only 和已有比较的：
- ΔBA、ΔW、ΔH、ΔrL、ΔrR；
- 参与者配对值、均值和配对区间；
- BA和W同时提高、只有一项提高、两项下降、零变化等完整联合分布；
- 每个类别真实样本数及缺失状态。

平局使用原数值容差；正、零、负要区分，不把零算成获益或下降。
动态 W 的较弱类别身份可以改变，应保留左右召回。必要时另做“固定参考方法的弱类别”描述，明确其定义和参考平局规则；不得用 query 表现为算法选择类别或参数。

这些是探索性补充终点，不替换历史主要 BA 终点。
BA、W、H有代数关系，不能当成三份独立成功证据。
类别差距缩小也可能来自强类别变差，不能省略两类召回后直接宣称两类均改善。

八、P1：EA错误转移、负迁移与概率质量
────────────────────────

A. 错误转移

对完全相同的 query，比较参考 a 与新方法 m。每个真实类别的样本数为 n_c，权重 w_j=1/(2*n_yj)：
C=sum_j w_j * 1[a错、m对]
I=sum_j w_j * 1[a对、m错]
ΔBA=C−I
D=sum_j w_j * 1[a与m的类别预测不同]

确认任务为二分类后验证 D=C+I。
C/I分母是整个类别平衡的 query 集合，不是只对参考错误或正确样本条件化后的比例。

重点计算 EA−Full，而非继续只解释旧 Full−LDA-only。
分别输出 Kumar 开发6人、主要12人、全18人次要汇总，以及 BNCI 9人；不得混用。

若论文3既存整合目录已计算同一论文2预测的 EA 分解，先核验输入哈希、ID、聚合和数值，复用可靠代码与结果。重放已有结果不能声称是新增独立发现。

已知历史整合稿中的 EA纠错/引错数值只能用于定位与核对，不应硬编码进结果。所有正文数字由本次验证后的结构化表读取。

B. 负迁移与效应分布

报告参与者和会话层面的正、零、负差值及分母，均值、中位数、范围和单参与者删除均值。
如报告负迁移会话比例，先在人内计算、再按原种子与参与者权重汇总，不让会话多的人占更大总体权重。
参与者平均均为正不意味着每个run均为正；单参与者删除不是独立外部验证。
极端正负值都核对试次数、类别数和预测，不自动删去，也不把未核实极端值当成亮点。

C. 概率指标

有真实概率或可按原定义重建的 logit 时，计算 balanced NLL 和明确版本的 Brier。
- 保留原概率映射、类别顺序、数值截断；有改变时记录敏感性版本。
- NLL按真实类别等权；Brier明确单坐标二分类式或双坐标和式，不能混用其数值尺度。
- 只有硬标签时，不反推或伪造概率。
- 概率变化比例与类别翻转比例分开。
- NLL/Brier改善不等于BA改善，也不单独证明概率已校准。

D. 支持拟合与后续泛化

如已有输出支持，区分支持集重代入表现、支持内留出表现和后续query表现。
不能把支持集训练损失下降称为泛化改善；query表现不进入更新选择。

十、P2：核对“EA−Full”是否只改变声称改变的操作
────────────────────────

逐项比对：
- source/support/query 的实际样本与权重；
- 输入通道、CAR与有效秩、正交基；
- 时间窗、滤波、采样率；
- 协方差计算、去均值、单位迹归一化、收缩和特征值下限；
- CSP成分、排序与功率特征；
- LDA求解器、收缩、先验及参数选择；
- 源数据与目标数据合并方式；
- EA参考估计范围；
- 无效数据、缺失类别及数值失败的处理。

重点核查 Kumar EA 使用21维CAR有效坐标时，Full是否做了可比的秩/坐标处理。不要仅凭正文没写就断言代码有错。
若证实还有实质性实现差异，保留历史结果，并新建匹配实现敏感性，使方法尽量只在对齐操作上不同。

跨数据集的源标签数40/96、参考方式、时间窗和估计器不同；不能把+5.47与+0.19的差异完全归因于数据集本身。
可在可行范围内增加统一核心CSP/LDA实现的敏感性，但不要机械统一不同任务的时间轴或改写历史主结果。

测试应覆盖：
- 身份与标签匹配、无意外重复；
- 改变query标签不影响拟合参数和预测，只改变评分；
- 无query信号进入参考估计、模型选择或归一化拟合；
- 预测阶段EA参考固定，无隐含query batch更新；
- 预期有效的矩阵对称性、正定性、有效子空间和有限数值；
- 错误转移恒等式、指标权重及百分数/百分点；
- 原始样本为空或缺类时按声明规则处理，不填假零、不借未来试次。

“支持集参考固定”并不意味着整个系统因果在线。零相位滤波及其上下文边界仍须如实说明。

十一、P2：把稳健性证据真正补到EA比较上

A. 查询端幅度敏感性

B. 支持端参考诊断

若信号可用，输出support类别组成、有效样本数、幅度标记率、参考矩阵谱与条件数、数值回退等。
关联分析明确为探索性，不从query挑选风险阈值再宣称可预测未来失败。
若做稳健参考估计对照，固定规则、保留全部方法结果；支持样本减少后的实际预算必须报告。

C. EA任务时间窗敏感性

确认原phase比较是否仅覆盖Frozen/LDA/Full。若是，在数据与标记可用时补EA。
比较共同合格试次上：5秒提示锚定与2秒任务锚定各自的EA−Full，以及二者的参与者级配对差值。
保持原资格范围；尽可能匹配训练/校准/测试身份，无法匹配处明确记录。
不能把缺失的任务标记虚构补齐；不能把筛选后范围说成完整原队列。
该比较同时改变锚点、时长和局部滤波边界，不写成单一因素的因果检验。
若本轮无数据无法运行，现有phase结果不得被改称EA稳健性证据。

十二、P2：从论文1/3迁移的最小机制对照

A. 简单尺度/协方差信息对照，优先执行

在同一数据划分、下游CSP/LDA与数值规则下考虑：
1. 原Full基线；
2. 逐试次公共RMS归一化后Full；
3. 域参考的对角信息归一化后Full；
4. 完整协方差EA后Full。

逐试次RMS改变保留的幅度信息，不是默认无害清洗。论文1的18通道160Hz输入不得直接替换论文2。
对角对照必须说明在哪个固定坐标系取对角；CAR有效坐标中的对角不自动代表原电极独立尺度。
若原下游归一化使某变换理论上或实际无效，报告该等效/空效应，不强行制造差异。
保持一次只改变可解释的因素，避免同时修改窗口、参考、协方差、模型后仍声称是单因素消融。

B. 对齐强度与协方差估计收缩分离，中优先

借鉴R8对alpha和eta的区分，但先检查论文2已有固定/经验锚定及EA组合。
论文3的目标白化后源重着色服务于冻结EEGNet；论文2分别处理源/目标后重拟合CSP/LDA。必须重新说明本管线中的变换路径、坐标和单位，不能直接复制R8矩阵公式和得分。
只使用在新query评价前固定的小规模对照；不从query选最优alpha/eta。
如使用身份映射与白化矩阵插值，先核实尺度/坐标约定，避免单位不一致而产生不可解释变化。

C. 协方差匹配与类别方向，选择性执行

R8的A(O)=R_s^(1/2) O C_t^(-1/2)、O正交，说明总体协方差匹配不唯一确定类别方向。
可用它设计有限的正确方向/反向/固定随机方向机制对照，或用于有出处的讨论。
但冻结网络结论不能直接外推到重新拟合CSP/LDA；是否有独立可辨识作用应先检查。
随机方向和重复种子不是新增独立参与者。
支持集协方差被白化是算法性质，不是未来泛化机制的充分证据。未来query可用于固定模型后的评价，不能反过来用于挑选变换。

D. 相关强参照，条件执行

有可靠原始定义或官方实现时，可增加一个与问题相关的标准对齐/几何参照。

不要为了模型数量重复训练大量神经网络。
