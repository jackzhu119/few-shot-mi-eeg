# Leeuwis2021 public EEG resource acceptance

Source: [DataverseNL DOI 10.34894/Z7ZVOD](https://doi.org/10.34894/Z7ZVOD),
[2021 study](https://doi.org/10.3389/fnhum.2021.634748), and its pinned
[NEMAR nm000327 v1.0.0 derivative](https://data.nemar.org/nm000327/v1.0.0/manifest.json).
The NEMAR release was deposited on 2026-10-08; this is a new mirror of the older
study, not newly collected participants. Original and mirror are one resource.
NEMAR `dataset_description.json` and the original DataverseNL v1.0 `termsOfUse`
both specify CC BY 4.0. Metadata responses and their hashes are retained.

The inspected source contains 55 resource participant IDs, one visit per ID,
one calibration run and three feedback runs. Each run has 40 left/right hand
motor-imagery trials. The planned bounded transfer selects 2,095 files,
568,544,461 bytes, including 220 EDF (566,607,360 bytes), root metadata, subject
sidecars and the source conversion metadata YAML. It omits 5,124,396,969 bytes
of `sourcedata` that duplicate original CSV downloads. Available disk exceeded
20 GiB at the transfer gate. The full official manifest has 2,320 files,
5,692,944,636 bytes; these larger totals are not the downloaded scope.

The transfer uses the existing `scripts/fetch_nemar_subset.py`: metadata/license
gate precedes signal transfer; every file must match its exact official size and
Git-blob or SHA256 checksum; mismatching existing files are preserved and rejected.

The representative EDF actually reads as 16 ordered EEG channels, 250 Hz,
80,000 samples. Stored physical units are µV; MNE returns volts. The source
reference is the right earlobe. The 40 originally stored 8-second trial segments
are concatenated, with 39 `EDGE boundary` rows that must prevent cross-trial
windowing. Cue onset in each stored segment is sample 749 (2.996 s); each task
annotation lasts 4.996 s. Source duration therefore spans 1,249 samples under the
explicit half-open `[start, stop)` convention used for identity fingerprints.
The upstream MOABB inclusive interval `[0, 4.996]` would span 1,250 samples.
Neither convention is silently imposed as a modeling window here; every source
row and exact boundary is retained. NETBCI's separate 5-second eligibility rule
does not apply to this resource.

Actual derivative codes are `EDGE boundary=1`, `left_hand=2`, `right_hand=3`.
The README/upstream adapter lists left/right as 1/2. Mapping uses the actual
TSV label/code pairs and matching EDF annotations, rather than the README's
different numeric codes. All participant age rows contain 20.71, the published
group mean, and sex is unavailable; these are not usable individual covariates.

The independent source audit (`scripts/audit_leeuwis_subset.py`) verifies all
selected source bytes, ordered channels, rate, physical units, every annotation
and source event, EDF endpoints and each task's concatenated-segment boundary.
It scans every continuous sample in bounded blocks, records flat channels,
exact whole-run numeric hashes, 4 KiB central fingerprints and exact task-window
hashes, and distinguishes within-ID from cross-ID duplicate groups. No tensors,
normalization, model fitting, trial padding or exclusions are performed.

The first transfer verified all 1,875 metadata files and 119 of 220 EDF, for
1,994 files and 308,420,173 bytes. The remaining 101 EDF failed with HTTP 503
generated by the session's Envoy proxy: its `cloudflare_https_tunnel` connection
returned `Invalid argument`. This was not an upstream S3 `SlowDown` response,
license refusal or checksum mismatch. Original failed receipts and diagnostics
are retained; no proxy/TLS settings were bypassed. This was the historical partial
state; the successful restored transfer and full acceptance are recorded below.

All 119 available EDF have now passed complete source-byte, continuous-value,
annotation and segment-boundary audits: 30 resource IDs, of which 29 have all four
runs and `sub-36` has three; 4,760 MI tasks (2,380 per class) and 4,641 EDGE rows.
No flat channels or exact whole-run/task-window duplicates were detected within
this available subset. The source durations are all 4.996 seconds. The partial
audit explicitly records `source_acceptance_complete=false`, 101 missing files
and `requested_available_scope_passed=true`; a zero exit from this deliberately
bounded available-only check does not mean the full planned resource is complete.
Fifteen rejection/identity tests plus Ruff passed. The machine-readable partial
audit is `research_logs/public_data_expansion_20261010/leeuwis_ingestion/`
`audit_available_run01/source_audit_summary.json`; its exact executed source is
preserved alongside it. This historical subset is retained alongside the new
full-resource audit, rather than being relabeled as complete.

On 2026-10-11, the unchanged official fixed-version path again returned HTTP 200.
The new immutable download receipt
`downloads/download_receipt_20261011T125339065971Z.json` reverified all 1,994 existing
files and downloaded the remaining 101 EDF, 260,124,288 bytes. All 2,095 selected

4.996 seconds / 1,249 samples under the recorded half-open fingerprint convention.
No continuous-run or source-task exact duplicates, cross-ID duplicate groups or
flat channels were detected in this complete derivative.

The original public non-EEG sidecars were also downloaded and individually match
DataverseNL v1.0 official SHA-1 checksums and sizes; new SHA256 digests are recorded.
These are `BCI_OnlineClassificationErrors.csv`, `Questionnaires.csv`,
`Data Report.pdf` and `readme.txt`: four files, 10,508,553 bytes, not duplicate raw
EEG downloads. The original source report states a 2020 data-production period.
The questionnaires contain 55 original IDs, actual individual ages 18–39 and the
original `Gender` field (36 Female, 19 Male). All 55 IDs match the mirror through
the saved upstream original-ID/file-ID mapping checked against official filenames.
An integer `sub-N` must never be equated directly with original participant N.

The online error table has 60 original IDs, four runs and two hands: 480 unique
subject/run/hand rows, each containing 2,000 finite percentage values (960,000
values, range 0–100). Only 440 rows match the 55 selected EEG IDs; original IDs
2, 6, 20, 35 and 64 have error curves but no selected EEG and do not add EEG
participants. The source readme defines each curve as an average over 20 trials,
covering eight seconds at 250 Hz, with the cue at three seconds. These curves are
not per-trial hit labels. Original participant 40 has irregular feedback EEG file
names; original signals/markers were not read, and no timing-specific trial joins
or feedback-sequence inference were invented. The reproducible sidecar audit is
`scripts/audit_leeuwis_sidecars.py`, with its receipt at
`leeuwis_ingestion/original_non_eeg_sidecars_audit_run01.json`.

This is an additional publicly licensed hand-MI resource for future, separately
specified training/transfer validation. It does not supply longitudinal days,
verified task-hit labels, unassisted retention probes or a causal learning
experiment. Resource ID counts must not be pooled into a global independent
biological participant count. Exact duplicate checks within the pinned derivative
cannot establish biological identity or rule out overlap with all other studies.
