# Task-aware adaptation: frozen descriptive analysis and next algorithm gate

本文件在本仓库首次 Kumar 模型性能计算前制定。当前论文题目为
**Task-Aware Adaptive Decoding for Longitudinal Motor-Imagery EEG**。
CPU 三基线及其主要比较由 `KUMAR_FROZEN_EXPERIMENT_PROTOCOL.md` 定义；本文件只增加
预先明确的探索性解释分析，不改变主终点、分区、模型、标签预算或失败排除规则。

## 实际数据与问题

使用 Kumar nm000177 v1.0.5 的18发布编号、6会话。开发编号固定为1、4、7、10、13、16，
最终测试为其余12编号。其他来源仅作归档或未来独立验证，不拼接成人数。数据已被探索性
审计，因此最终测试是固定的同库留出，不称未接触的外部确认。年龄、GR/PAR归属和真实
闭环行为终点无法核实，不据此作调整或因果推断。

研究问题是总分布漂移与源任务相关信息变化，分别能解释多少冻结解码器跨会话性能变化。
这些是回顾性离线解释，不是神经学习、可塑性或技能保持的证据。

## 固定解释变量

每个编号的参考比较使用独立 `source_query`，后续比较使用共同 `target_query`。
所有源特征和尺度均只在 `source_train` 拟合。

1. 总信号漂移：使用预定义 HelmertCAR21、迹归一化和0.1收缩协方差，计算每trial到
   固定源训练 Riemann 均值的距离。后续query均值减参考query均值是会话变化量。
2. 任务相关漂移：在源训练的44维标准化Mu/Beta功率中，计算左右类均值差并归一化为
   固定任务轴。计算源query与目标query在该轴上的一维Wasserstein距离；目标标签不参与
   此变量计算。若源方向范数为零，标记不可估计，不换特征。
3. 次要描述：在固定源PCA4、任务轴和功率坐标中报告类分离、Mu/Beta变化、预测比例和
   类别坍缩。使用目标真标签的类分离明确标为监督回顾性描述，不称未标记数据的预测量。

端点为冻结BA目标会话减源query BA。五个会话不是五个独立参与者。先在开发编号作
描述性Spearman关联；最终留出按相同固定变量报告关联和差值，不搜索特征或阈值。
对会话级关联的区间以参与者为块做2,000次bootstrap、seed42，不按trial或session重采样。
同时报告每编号五会话均值的关联，避免重复测量数量制造虚假精度。小样本结果仅探索性，
不宣布确认性显著性或最优预测模型。总漂移和任务漂移数值单位不同，不比较原始斜率。

## 固定敏感性和可用性

主分析保留所有完整窗口及固定250µV p2p标记。另报告无该标记的query诊断、每类按
时间顺序取相同数量的诊断、全部22通道与C3/Cz/C4功率变化。诊断只改变描述性统计，
不重新训练、不挑选主结果；不足两类或少于两个trial的分组记不可估计。
源CPz采集参考是元数据声明，CAR处理不能重建原始CPz信号；原始参考敏感性仍Pending。
0.1协方差收缩为固定测量定义，不在测试query调参。任务方向在开发/测试各参与者自己的
源训练中定义，不借用该参与者后续标签或跨编号最终测试结果。

## 最小新策略的决策条件

在实际基线和上述诊断完成后，检查重校准是否在相同标签预算下使部分参与者恶化、
是否出现类别坍缩，以及大协方差漂移是否伴随较小任务轴变化。不得为了展示创新而挑选
少数成功参与者或复杂模型。算法实施仍Pending，以下是可证伪候选，而非已有效的方法。

候选为基于当前允许support的任务信息门控：源模型和常规更新模型各自使用相同source与
support预算；门控只根据support中可估计的任务分离可靠性和模型变化，决定保持或更新。
阈值只能在开发参与者、按trial/run分组的嵌套验证内固定，随后只运行一次最终测试。
对照包括始终冻结、始终常规更新、同预算固定混合和仅协方差变化门控。
报告平均BA、参与者恶化比例、类别坍缩、更新次数、标签数、耗时及未来会话的独立性能。
门控决策不能读取目标query、未来support或未来标签。没有稳定开发证据时，不实现新策略，
保留失败模式及测量可靠性问题；下一阶段另冻结配置、分区和源码。

EEGNet正式充分训练另见 `EEGNET_TRAINING_PLAN.md`，当前不采购GPU或付费算力。
离线算法比较不依赖在线人体实验；不生成论文Release，不自动投稿。
